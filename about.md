# Editor Eyedropper

Tired of guessing RGB values? **Editor Eyedropper** adds an eyedropper tool to the editor's colour picker, so you can grab a colour from anywhere on screen and use it instantly.

## Features
- **Eyedrop button** in the colour select popup (Base/Detail colours in Edit Object, Color triggers, and more)
- **Freezes the editor view** so you can pick from any object or background
- **Live preview** with a swatch and hex code that follows your cursor or finger
- Works with mouse
  
## How to use
1. Open the editor and select an object
2. Open **Edit Object** and click a colour button
3. Press the **Eyedrop** button
4. Click or tap a colour on screen and release to apply it
5. Press **Esc** to cancel

## Notes
The colour is read from what's rendered on screen, so effects like glow, blending and lighting can change the result compared to the object's raw colour.
