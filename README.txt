Editor Eyedropper

A Geode mod for Geometry Dash 2.2081 that adds an eyedropper to the editor's colour picker. Sample any colour straight from the screen instead of typing in RGB or hex values.

Features
Eyedrop button in the colour select popup (the one you get from an object's Base/Detail colour in the Edit Object page, or from a Color trigger).
Freezes the editor view so you can pick from anything visible: objects, backgrounds, glow, blending.
Live preview with a swatch and hex code that follows your cursor or finger.
Works on desktop and mobile (tap or drag, release to confirm).
Usage
Open the editor and select an object.
Open Edit Object and click a colour button (Base or Detail).
Click the Eyedrop button at the bottom-left of the popup.
Tap or drag over the screen to preview a colour, then release to apply it.
Press Esc (or the back button) to cancel.
